## 先读什么

1. 成交与评价可信度：K-000006 队列反应模型 → K-000007 ABIDES → K-000015 回测过拟合 → K-000025 RL 评估可靠性 → K-000011 正规评分规则。
2. 可解释做市与概率：K-000003 库存偏斜 → K-000004 库存风险 → K-000005 订单簿动态 → K-000010 价格与概率的边界 → K-000009 预测市场综述 → K-000008 LMSR。LMSR 是另一类市场机制，不能拿它替换 CLOB 成交假设。
3. 训练重构：K-000020 GAE 边界 → K-000019 PPO → K-000021 TRPO 的约束思想 → K-000022 实现细节 → K-000024 GRU → K-000023 部分可观测循环记忆。公开项目训练路线暂停重构，以上是设计依据，不触发恢复训练。
4. 校准与连续观察：K-000012 温度缩放 → K-000013 自适应保形覆盖 → K-000014 置信序列。动作概率不等于事件概率；长期覆盖不等于每个市场条件覆盖。
5. 机制边界：K-000016 MEV 与结算风险 → K-000017 LVR → K-000018 批量竞价。历史以太坊、CFMM、证券交易机制不能直接等同当前二元 CLOB。
