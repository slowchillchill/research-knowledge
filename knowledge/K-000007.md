# K-000007｜ABIDES: Towards High-Fidelity Multi-Agent Market Simulation

## 方法与作者证据

用离散事件消息内核模拟代理、交易所、计算耗时及网络延迟，并展示互动和冲击实验。架构支持受控压力测试，但真实程度取决于背景代理与校准。

## 对公开项目的迁移判断

应在确定性的配对回放之后，用来检验延迟、撤单竞态与信息跳变敏感性；先消除请求编号影响延迟的比较偏差。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

建立小型固定市场，让策略共享外生信息与背景流随机数；延迟绑定稳定的外生事件和操作类别，而不是随策略变化的请求编号。扫描真实可行延迟、事件同刻排序和信息跳变，再用独立真实数据核验成交统计。

预计投入：4–8 engineer-days for a scoped prototype; production integration is substantially larger.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若无意义地重命名请求编号、改变同刻事件排序或采用合理延迟分布就改变排名，或模拟成交统计无法通过留出集验证，则否定性能结论。

## 使用边界

- 所有交互须经过显式计时的事件队列。
- 背景流与撮合规则决定模拟质量；所读版本对同一纳秒事件采用任意顺序。
- NASDAQ 风格基础设施不会自动实现二元结算、抵押规则或目标平台费用。
- 后续 JPMC 仓库已于 2025-06-02 归档，依赖兼容性未运行验证。
