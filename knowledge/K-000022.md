# K-000022｜Implementation Matters in Deep Policy Gradients: A Case Study on PPO and TRPO

## 方法与作者证据

控制 PPO/TRPO 的代码级差异，发现缩放、初始化、value clipping 等会显著改变所测任务的表现与更新行为。

## 对公开项目的迁移判断

比直接扩模型更适合优先排查训练可复现性。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

导出完整训练配置；做 reward scaling × value clipping 的 2×2 对照，冻结训练集归一化并保留原始扣费收益。

预计投入：1–2 engineer-days for manifest and four configuration switches; 4 variants x 3 paired seeds as pilot. Broader grids only after identifying a concrete failure. Estimates assume required simulator/trainer interfaces and logs exist; do not include implementing the full PAPER/LIVE entry or resuming paused training.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若收益依赖泄漏、混杂改动或不稳定的种子/调参，不接受该开关有效的结论。

## 使用边界

- 需要同调参预算与完整配置清单；先固定其他因素再消融。
- 不能推导所有场景都应打开某开关，也不能推导 PPO 裁剪普遍无用。
