# K-000015｜The Probability of Backtest Overfitting

## 方法与作者证据

将全部尝试的策略收益矩阵用于组合对称交叉验证，估计样本内优选策略在样本外排名失效的风险。

## 对公开项目的迁移判断

七参数变体和未来PPO超参数选择的试验登记与过拟合诊断。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

拟议：先统一共享外生延迟，再保存所有配置的同日期净收益矩阵；增加独立时间留出，以CSCV作补充敏感性诊断而非取代留出。

预计投入：1–2 天，依赖多窗口输出；未执行。。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若结论随分块剧烈改变或留出持续失效，不采纳样本内赢家。

## 使用边界

- 记录全部试验而非只保留赢家；统一成本、时间对齐和收益口径。
- CSCV不是实时可交易walk-forward的替代；分块与非平稳性仍影响解释，不能把单个概率当未来收益承诺。
