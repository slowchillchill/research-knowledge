# K-000023｜Deep Recurrent Q-Learning for Partially Observable MDPs

## 方法与作者证据

在 DQN 中加入 LSTM，用连续单帧历史处理部分可观测性，并讨论循环更新的初始状态。

## 对公开项目的迁移判断

为检验做市器是否确实需要隐藏订单流与延迟回报的记忆提供基础。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

在重设计中比较单快照 MLP、短历史 MLP、GRU；同容量和输入，再做公共行情延迟/丢包压力测试，保留自身订单状态。

预计投入：1–2 engineer-days if GRU rollout storage exists; three architectures x 3 paired seeds, then held-out latency/dropout stress tests. Estimates assume required simulator/trainer interfaces and logs exist; do not include implementing the full PAPER/LIVE entry or resuming paused training.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若短历史基线同样好、压力场景收益消失或 episode 边界仍错误，不支持引入记忆的收益主张。

## 使用边界

- 原文为 Atari 上的 LSTM Q-learning，利用闪烁画面制造缺失观测；不是 GRU PPO。
- 记忆不一定优于显式短历史；有限反向传播与错误状态初始化会损失信息。
