# K-000025｜Deep Reinforcement Learning at the Edge of the Statistical Precipice

## 方法与作者证据

建议用 bootstrap 区间、性能分布与稳健汇总呈现 RL 比较的不确定性，避免只报单点均值。

## 对公开项目的迁移判断

为是否接受任一做市改动提供统计与经济判据。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

先对两个已有模型按配对留出合约/时段出报告，分别刻画训练种子和市场窗口不确定性，按合理时间块重采样；预先声明收益门槛与尾部限制。

预计投入：1–2 engineer-days if per-episode logs exist; evaluation can run on saved checkpoints before any retraining. More days of independent market data may matter more than more bootstrap resamples. Estimates assume required simulator/trainer interfaces and logs exist; do not include implementing the full PAPER/LIVE entry or resuming paused training.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若区间同时覆盖实质收益与损失、合理分块改变结论或尾部约束失败，不能宣称胜出。

## 使用边界

- 需多次训练与一致评估协议；市场数据存在时间和合约相关性，不能把每笔成交当独立样本。
- bootstrap 无法修复泄漏或偏差；IQM 也不能替代金融尾部损失与回撤。

未训练、未回测、未交易。使用前通过来源卡 [S-000025](../sources/S-000025.md) 核对版本及全部适用条件。
