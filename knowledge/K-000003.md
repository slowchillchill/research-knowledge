# K-000003｜High-frequency trading in a limit order book

## 方法与作者证据

用随机价格、成交强度和效用目标推导库存偏斜报价。论文的模拟显示库存与盈亏波动下降，但平均收益也略降；这是风险控制证据，不是 BTC 实盘收益证据。

## 对公开项目的迁移判断

作为可解释的库存管理基线，把预测信号收益与风险暴露控制分开；一次七小时回放不能替代独立验证。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

在相同外生事件流、固定事件级延迟样本、费用与风险限制下，配对比较对称报价和库存偏斜报价。使用队列感知成交与实际结算盈亏，按事件日期划分独立留出集，报告配对净收益差、尾部损失、峰值库存与成交后价格变化。

预计投入：1–2 engineer-days with a clean dataset and working replay engine.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若留出集上同等换手下的库存集中或尾部风险未改善，或仅将延迟从请求编号解耦就改变策略排名，则不接受风险控制或收益提升结论。

## 使用边界

- 基准价格为恒定波动率的布朗运动，基础模型没有预测漂移。
- 指数效用、有限期限及泊松成交；允许连续且无成本地更新报价。
- 没有真实延迟、撤单竞态和精确队列优先级。
- 无界价格与期末盯市目标不能直接代替二元合约的 0/1 结算。
