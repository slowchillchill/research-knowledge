# K-000011｜Strictly Proper Scoring Rules, Prediction, and Estimation

## 方法与作者证据

以严格适当评分评估概率，避免评价规则奖励夸大信心。二元事件可用 Brier 与 log loss；论文的理论和天气案例说明评分选择会改变模型优劣判断。

## 对公开项目的迁移判断

predict-market-analysis 与 BTC 概率预测的离线评价契约。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。
