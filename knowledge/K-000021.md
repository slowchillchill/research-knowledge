# K-000021｜Trust Region Policy Optimization

## 方法与作者证据

以近似平均 KL 约束优化替代目标，使用共轭梯度与线搜索；实用算法是理论保证的近似。

## 对公开项目的迁移判断

帮助解释 PPO 仍需监控策略变化，优先作为诊断基础。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

先提议给 PPO 加 KL 早停对照并检查高库存状态的变化尾部；仅当问题仍存在时再做同特征的前馈 TRPO 基线。

预计投入：0.5–1 day for PPO/KL audit; 2–4 days for a separate TRPO baseline if reusable code and simulator API exist. Do not prioritize a full optimizer rewrite. Estimates assume required simulator/trainer interfaces and logs exist; do not include implementing the full PAPER/LIVE entry or resuming paused training.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若不减少不稳定更新，或增加成本却无稳健留出收益，则不推进优化器替换。

## 使用边界

- 理论依赖更强的优势与散度条件；有限样本、平均 KL 和实际动作执行需要分别检查。
- 实用 TRPO 不保证交易收益；实现与计算成本高于简单 PPO 更新。
