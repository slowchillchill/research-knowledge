# K-000006｜Simulating and Analyzing Order Book Data: The Queue-Reactive Model

## 方法与作者证据

在参考价固定的区间内，让订单事件强度依赖当前队列状态，并通过状态切换衔接价格变化。论文明确提醒：均匀分配撤单位置可能高估成交，因为低优先级订单更易撤销。

## 对公开项目的迁移判断

成交真实性的最高优先级基础：队列推进、撤单位置和状态相关事件率，都可能比策略本身更能解释短回放中的表面优势。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

训练状态相关强度后，先核对留出集深度、价差、事件间隔和不利变价前成交概率，再比较保守、均匀及订单标识支持的撤单模型。策略配对共享外生事件，延迟不依赖请求编号；只有 L2 时报告成交及收益区间。

预计投入：4–7 engineer-days for a compact simulator and validation.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若模拟器不能重现留出集成交与订单簿统计，排名依赖乐观撤单，或成交不确定性大于策略优势，则不能用其排名结果支持上线。

## 使用边界

- 给定当前订单簿状态后，订单流按马尔可夫过程建模，并假设价格时间优先。
- 稳定性依赖负漂移与有界到达；准确检验位置相关撤单需要订单标识。
- 原始验证是大 tick 股票，不是临近到期的二元合约。
- 缺少订单标识时成交估计可能乐观；原始研究排除了开收盘时段，不能直接外推到到期冲击。
