# K-000008｜Logarithmic Market Scoring Rules for Modular Combinatorial Information Aggregation

## 方法与作者证据

把连续修订概率报告转换为与做市商的交易。对数形式能保持指定的条件概率关系并支持模块化信息聚合；资金约束是机制设计结论，不是预测准确率保证。

## 对公开项目的迁移判断

适合建立概率一致性与机制认知基准；若实际平台是 CLOB，其实施优先级低于成交真实性验证。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

实现数值稳定的二结果 LMSR 参考计算，检查互补概率之和、交易成本路径无关性，并枚举终局验证均匀初始状态下的亏损界限。该测试与实际 CLOB 撮合和七策略回放分开使用。

预计投入：0.5–1 engineer-day for a mathematical test harness.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若概率和不为一、拆分相同交易路径改变总成本，或满足假设时终局损失超界，则实现有误；通过这些测试也不能证明 CLOB 策略有效。

## 使用边界

- 明确互斥完备的结果空间、初始概率和流动性参数。
- 诚实报告激励依赖效用与事件相关性等假设。
- LMSR 运营方的补贴或亏损界限不同于 CLOB 做市者的库存风险。
- 组合状态空间有计算成本，不能据此假定目标平台当前采用 LMSR。
