# K-000028｜市场冲击的反事实与区间验收

## 作者报告与测量对象

市场冲击问的是有无自身订单的路径差，而非仅预测未来价格。论文以隐藏信息流、订单流和价格三变量先验训练 4.2M 参数 PFN，并与无干预输入的 twin、AC、OW、平方根、回报回归、last-value 和 oracle 比较。传统基线仅拟合事件前窗口，模型遮蔽干预后观察（S-000029 `architecture-prior`）。

ABIDES 以相同 seed 运行有无 metaorder，silent twin 保留 agent seed 与 latency；探索为 0–999，冻结评估为 1000–1999。15分钟、约25%–40%参与率、30秒bar设置下，作者报告配对 do-head 效应 0.38σ [0.34,0.42]，偏差 0.08σ [-0.27,0.42]，逐episode相关仅0.11；这不支持逐笔高准确率结论（`abides`）。

真实 BTC/ETH/SOL 2026年4–6月共2,278个 detected bursts，没有真实反事实，也不是已验证 liquidation 标签。平方根法的事实预测 RMSE 为2.1–2.5σ且偏差较小，因而不能从该比较断言模型已正确恢复真实因果冲击。recurrent 的0.92–0.96相关来自12个duration×size格均值；主要改善来自逐步注入干预，不能全归因于换RNN（`real-bursts`）。

## 区间与工件限制

名义80%区间的覆盖率在ABIDES为32%、BTC为47%、ETH为51%。ABIDES区间表使用探索seed；conformal以0–499校准、500–999评估，将覆盖提至约82%但需约4倍宽度，不是冻结1000–1999测试的新结果（`intervals`）。

先验未建模队列、撤单或库存。官方ARTIFACT公开recurrent权重，Transformer权重及ABIDES/Binance缓存缺失；不认定完整实验已可直接复现。手续费、价差、部分成交、到达延迟和预测市场结算未形成统一端到端验证（`limits-artifacts`）。

## 公开工程迁移判断

整理者建议借鉴反事实正确性和区间校准验收，暂不直接替换做市成本模型。固定历史价格回放不能识别自身订单冲击，也不能充当反事实真值。可结合 [K-000007](K-000007.md) 的仿真边界阅读；没有自动添加科学支持、冲突或替代关系。

## 最小拟议实验与否证（未执行）

在独立公开或合成事件驱动sandbox固定20–30组情景和公共随机数，有无测试订单分支保留同调度/延迟。按seed及日期隔离训练、校准、测试，先检验零冲击、已知线性与饱和冲击，再比较OW、平方根与现有成本假设。

报告配对冲击偏差/RMSE、80%区间覆盖及宽度、费用后成交成本，单列队列、部分成交、时延与结算压力。已有接口与干净数据时，小样本检查估计1–2工程日；数据取得、新训练与完整生产集成另计。若基线正确性不能重现，或独立测试无改善且区间更宽，则停止模型替换。
