# K-000009｜Prediction Markets

## 方法与作者证据

综述预测市场的预测证据，区分概率、均值和中位数对应的不同合约支付，并讨论长赔率偏差及与期权推导事件价格的比较。

## 对公开项目的迁移判断

提供合约定义、结算与基准对齐清单，避免把短回放中的价格差异直接解释成预测优势。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

审计 BTC 合约结果、结算来源、到期与可获知时间。在独立已结算事件组中，按期限、流动性和概率区间比较市场中间价与简单波动率基准的适当评分及校准；可执行买卖价格和费用另行评价。

预计投入：1–3 engineer-days with trustworthy resolution labels.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若优势来自结算或到期错配、不能通过独立事件组，或改用可执行报价后消失，则不接受预测或交易优势结论。

## 使用边界

- 先对齐支付、事件定义及到期时间，再解释价差。
- 期权隐含价格还涉及风险溢价，不能自动视为真实事件概率。
- 主要是现代加密预测市场出现前的异质历史证据。
- 集体预测准确不等于做市净盈利；中间价差异未必能在买卖价差与费用后执行。
