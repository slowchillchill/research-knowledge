# K-000020｜High-Dimensional Continuous Control Using Generalized Advantage Estimation

## 方法与作者证据

用指数加权 TD 残差估计优势；gamma 与 lambda 的偏差来源不同。论文在 TRPO 控制任务上验证。

## 对公开项目的迁移判断

用于延迟成交、库存持有和结算奖励的信用分配正确性。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

先用手算轨迹测试结算、截断和 padding，再对比 lambda 0.90/0.95/1.0。另行提议按 elapsed time 折扣，不能归为原文结论。

预计投入：0.5–1 day for correctness tests; 1 additional day for elapsed-time discount plumbing if delta_t already exists. Three lambda variants; timing ablation only after correctness passes. Estimates assume required simulator/trainer interfaces and logs exist; do not include implementing the full PAPER/LIVE entry or resuming paused training.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

手算不一致即停止；新折扣或 lambda 若无法在独立时段稳定改善且守住尾部风险约束，不采纳。

## 使用边界

- 先定义经济折扣目标、critic、真实终止与截断的 bootstrap 掩码；保留事件时序。
- critic 不准会影响 lambda 小于 1 的偏差；原文按步折扣，未验证不规则市场事件。
