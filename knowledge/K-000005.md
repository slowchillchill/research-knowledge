# K-000005｜A Stochastic Model for Order Book Dynamics

## 方法与作者证据

建立可解析的连续时间订单簿模型，估计给定队列状态下的价格变化与成交概率，并用东京证券交易所观测和模拟说明。核心是条件成交风险，而非触价必成交。

## 对公开项目的迁移判断

作为可审计的“价格不利变化前成交”基线，检验七小时回放中的收益是否主要来自过于乐观的成交假设。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

用较早日期拟合条件成交概率和下一次价格方向，在独立后续日期比较校准与评分损失。以无条件基准和触价成交规则作对照，再让七个策略共享同一外生事件流，量化替换成交规则后的收益变化。

预计投入：2–4 engineer-days for a compact queue benchmark.。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若留出集成交概率持续过高、不能优于无条件基准，或考虑真实队列后无法解释成交时机，则拒绝把此模型用于策略排名。

## 使用边界

- 订单到达与撤单采用简化的独立泊松类机制。
- 需要足够细的历史订单簿观测来估计参数；概率结论依赖模型成立。
- 明确忽略交易者战略互动和订单流长记忆。
- 突发新闻或 BTC 大幅波动时，平稳性与独立性假设容易失效；可访问手稿的具体修订日期未确认。
