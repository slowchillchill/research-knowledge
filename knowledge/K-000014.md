# K-000014｜Time-uniform, nonparametric, nonasymptotic confidence sequences

## 方法与作者证据

构造全时间有效的置信序列，避免重复查看固定时点区间造成错误发现。Theorem4 针对有界观测的平均条件期望，并不要求共同均值。

## 对公开项目的迁移判断

持续观察 Brier 差值等有界指标时保留统计有效性。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

拟议：对锁定的两种概率预测器，逐已结算事件更新有界 Brier 差置信序列；以固定时点区间为演示对照，并做已知零差模拟检查越界率。

预计投入：1–2 天；未执行。。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若模拟覆盖不达标或数据不能满足界的条件，不用于提前判胜。

## 使用边界

- 原始未界定交易损益不可直接套有界公式；时间统一性不自动修复数据泄漏、多策略选择或错误标签。
