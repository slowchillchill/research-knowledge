# K-000013｜Adaptive Conformal Inference Under Distribution Shift

## 方法与作者证据

以已观测误覆盖反馈调整预测集阈值，研究分布变化时长期覆盖。股票波动率和选举实例支持其作为在线不确定性工具。

## 对公开项目的迁移判断

市场状态漂移监测和价格/波动区间，作为报价风险输入的候选。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。
