# K-000016｜Flash Boys 2.0: Frontrunning, Transaction Reordering, and Consensus Instability in Decentralized Exchanges

## 方法与作者证据

实测早期以太坊交易排序竞争，提出PGA和MEV风险框架。链上可见成交只揭示部分竞争过程，提交顺序不能视为最终执行顺序。

## 对公开项目的迁移判断

execution-normalization/ledger研究：分别记录提交、撮合、链上确认和最终结算。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

拟议：用合成事件注入重排、延迟确认、拒绝、重复回执，断言资金预留与结算幂等，比较理想即时确认路径。

预计投入：1–2 天，测试设计/原型；未执行。。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若只在理想回执顺序账目一致，不能以现有仿真宣称结算稳健。

## 使用边界

- 适用于有排序依赖的链上执行风险分析；需另核目标链与撮合机制。
- 历史PoW Ethereum证据不能量化当前Polymarket/Polygon风险；作者仅覆盖部分DEX和可识别机器人。
