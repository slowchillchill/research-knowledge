# K-000012｜On Calibration of Modern Neural Networks

## 方法与作者证据

固定模型后用一个温度参数校准 logits。视觉和 NLP 实验显示其经常降低校准误差，但并非所有数据集最佳。

## 对公开项目的迁移判断

给市场概率头增加低成本校准基线；不能将 PPO 动作概率当事件胜率。

下述迁移为整理者推论，论文未验证本项目收益。项目上下文固定为公开 README 的 96430c0b8330f3cb42e8dd7bdaf9ab6efd68f2a4 版本；历史训练路线处于重构暂停状态。

## 最小实验提议（未执行）

拟议：冻结同一概率模型，按时间拆分训练/校准/测试；比较原始、温度、常数概率，评价 Brier、NLL、分时段校准及样本量。

预计投入：0.5–1 天，不含新模型训练；未执行。。这是在人力、数据与仿真器前提成立时的估计；算力费用、排队及数据授权成本未测。

## 否证与停止条件

若后续日期 proper scores 不改善或恶化，则不采用固定温度。

## 使用边界

- 只用独立校准集拟合温度；保持测试集封存。
- 论文不是市场研究；时间漂移后温度可能失效。ECE 受分箱影响，须同时报告 proper scores。
